Vos données restent uniquement sur cet appareil, dans ce navigateur : elles ne sont envoyées à aucun serveur. Elles peuvent contenir des données personnelles (noms, téléphones, notes) : protégez vos exports.

Démarrer

  1. Téléchargez votre commune : Secteurs → Communes, ou tapez son nom dans la recherche (Ctrl K). Tous ses bâtiments et adresses (IGN) arrivent en une fois, avec une barre de progression.
  2. Ou zoomez sur une rue et touchez « Charger les maisons de cette zone » en bas de la carte.
  3. Secteurs : dessinez votre zone pour suivre le pourcentage couvert.
  4. Sur le terrain, démarrez une tournée (bouton lecture du dock) et passez en pointage rapide : touchez chaque maison faite.
  5. Suivez vos résultats dans Bilan et vos personnes à recontacter dans Rappels.

Les outils

  • Consulter : touchez une maison pour ouvrir sa fiche (statut, contact, note, historique).
  • Pointage rapide : choisissez un statut, chaque maison touchée le reçoit. Annuler est proposé à chaque fois.
  • Tournée (bouton lecture) : chronomètre, portes, contacts et distance de votre sortie ; bilan, records et défis à la fin.
  • Sélection multiple : entourez plusieurs maisons (rectangle ou lasso) pour leur appliquer un statut.
  • Ajouter : placez une maison absente de la carte.

Bâtiments et immeubles

  • Types : maison, immeuble, habitation avec commerce, entreprise, équipement, annexe… d'après l'IGN. Dans la légende, choisissez les types affichés et comptés ; corrigez un type dans la fiche.
  • Immeubles : un geste marque tous les logements (prospectus dans toutes les boîtes) ; chaque logement compte pour une porte. Ajoutez un logement pour suivre une personne (statut, contact, rappel) ; notez le digicode, l'interphone, le gardien.
  • Vue éloignée : la carte montre l'avancement par carreaux (vert = logements faits) ; zoomez pour voir les bâtiments.
  • Téléchargements : en cas de coupure ou de fermeture, ils reprennent là où ils s'étaient arrêtés ; Pause et Annuler dans la carte de progression.
  • DPE et ventes : la fiche montre l'étiquette énergie des logements (ADEME) et les ventes depuis 2021 (DVF) ; filtrez les passoires F/G ou les biens vendus dans la légende et la Base.
  • Ordinateur ↔ téléphone : Données → Synchroniser. Un appareil affiche son QR code, l'autre le scanne et affiche sa réponse, que le premier scanne. Même Wi-Fi conseillé.

Suivi commercial

  • Statuts commerciaux : après un contact, passez la maison en Estimation faite, Mandat signé ou Mandat concurrent / vendu. L'historique garde chaque étape.
  • Qualification (fiche) : potentiel chaud / tiède / froid, projet, échéance, propriétaire ou locataire. Les prospects chauds remontent dans le Bilan et les Rappels.
  • Étiquettes : vos repères rapides (Stop pub, Chien…). Créez-les depuis la fiche (« Nouvelle ») ou la recherche (« Gérer les étiquettes »).
  • Filtrer la carte : dans la légende, n'affichez que les maisons d'une étiquette, d'un potentiel ou d'un projet.

Sur le terrain

  • Ma position : point bleu suivi en direct ; l'écran reste allumé pendant le suivi. Votre position n'est jamais enregistrée ni envoyée.
  • Installer l'application depuis le menu du navigateur (« Installer » / « Ajouter à l'écran d'accueil ») : elle démarre ensuite sans connexion, avec vos données.
  • Hors ligne, les maisons déjà chargées restent cochables ; seul le fond de carte demande du réseau.

Bon à savoir

  • Les maisons viennent d'OpenStreetMap : certaines manquent ou n'ont pas d'adresse ; un immeuble compte pour un bâtiment (indiquez le nombre de logements).
  • Tout est enregistré dans ce navigateur : exportez régulièrement depuis Données.
